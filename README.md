# ⭕ 三目並べ ❌ (Tic-Tac-Toe)

Vincent と Jolly が作った三目並べゲームです。
A tic-tac-toe game built by Vincent & Jolly. 🐷

## 遊び方 / How to play

- `index.html` をブラウザで開くだけで遊べます。 Just open `index.html` in a browser.
- ふたりで対戦 / 2 players、またはコンピュータと対戦 / vs computer (かんたん・つよい)。
